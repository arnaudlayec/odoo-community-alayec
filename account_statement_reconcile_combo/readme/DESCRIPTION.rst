
This module is a *last-hope* solution for accountants that needs to reconcile
groupped bank statement lines, like all the groupped credit card per day,
with recent customer invoices.

It was designed for an e-commerce use-case where customers pay products by
credit card with the LCL French bank CB solution. Indeed, LCL does not provide
line-by-line transactions amounts but groups them with their own logics.
