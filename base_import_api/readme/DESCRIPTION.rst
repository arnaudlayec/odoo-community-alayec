
This base module exposes a new public endpoint `import_api` for importing data from
an external system to Odoo using the native XML-RPC format. By itself, it does not provide
any business feature.

It aims at letting Odoo developpers only the tasks of writing the logic of data import,
by inheriting the mixin `import.api.mixin` and overriding the method `_run_import_api()`.
It also offers simple end-user tools to review API calls history and ease debugging.

For a full example, please check at module `account_invoice_import_xmlrpc`.

Note: example of scripts to interract from an external system with Odoo XML-RPC API are
given in `static` folder (code generated by an IA agent).
